## 1교시: 컴퓨팅 사고

### 업다운 게임 (1~N 숫자 맞히기)
- 전략: 남은 후보의 **가운데**를 부르면 대답이 업이든 다운이든 후보가 절반으로 준다.
- 1~100은 최악의 경우 **7번** (50 → 25 → 12 → 6 → 3 → 2 → 1).
- 1~1,000,000을 처음엔 **1000번**이라고 답했다가 틀림.
- 발견한 규칙: **범위가 2배가 되면 횟수는 1번 늘어난다.**
  `횟수(n) = 1 + 횟수(n/2)` 이므로 1,000,000은 **20번** (2²⁰ = 1,048,576).
- 실수: `1 + 1000000/2`처럼 **횟수와 개수를 더함**. 단위가 다른 값은 더할 수 없다.

| 배운 것 | 정식 이름 |
|---|---|
| 가운데 부르기 | 이진 탐색, O(log n) |
| 2배 → +1 | log₂ |
| 1 + 절반 크기의 같은 문제 | 재귀 |

### 슬라임 기획서 v1.0
**상태**
- 정지: 이동속도 = 0
- 이동: 방향을 주기적으로 랜덤으로 바꾸며 이동
- 적대적: 플레이어 쪽으로 이동
- 공격: 멈춤 → 0.5초 준비(선딜) → 플레이어 쪽으로 튕기며 공격 → 0.2초 철푸덕(후딜)
- 사망: 나가는 전환 없음

**전환**
```
정지 --(3초마다 1~10 난수, 4~10)--> 이동
이동 --(3초마다 1~10 난수, 1~3)--> 정지
정지, 이동 --(거리 5칸 이내)--> 적대적
적대적 --(거리 8칸 초과)--> 이동
적대적 --(공격 사거리 안)--> 공격 --(후딜 끝)--> 적대적
아무 상태 --(HP 0)--> 사망
```

**설계 근거**
- 인식 5칸 / 해제 8칸 (히스테리시스): 같으면 경계에서 인식이 됐다 풀렸다 하며 꼼수가 생긴다. 50칸이면 끝까지 쫓아와서 불쾌하다.
- 공격 후딜은 정지 상태로 보내지 않고 공격 안에 둔다. 정지 상태에는 난수 전환과 인식 전환이 딸려 있어서 쉬는 시간이 0초가 될 수 있다.
- 시간이 걸리면 상태, 한순간이면 이벤트.

**확률 계산**
- 오래 보면 정지 비율은 **30%** (큰 수의 법칙).
- 처음엔 이미 정지한 슬라임이 또 정지할 확률을 0.3 × 0.3 = 9%로 틀림. 이미 일어난 일은 빼야 하므로 **30%**.
- 평균 쉬는 시간 = 3 × (1 + 0.3 + 0.09 + 0.027 + …) = 3 × 1/0.7 ≈ **4.29초**.

**v1.1에서 고칠 것**: 공격 사거리 숫자, 플레이테스트 체크리스트.

## 2교시: 슬라임을 C++로

코드: [gamedev-practice/01-slime/slime.cpp](../gamedev-practice/01-slime/slime.cpp)

### 상태 저장 방식 비교
| 방법 | 장점 | 위험 |
|---|---|---|
| `int` | 가볍다 | 사람이 읽기 어렵고 `state = 7`도 통과 |
| 문자열 | 읽기 쉽다 | 오타를 실행해봐야 앎 |
| `enum class` | 이름 + 숫자 | 실수를 **컴파일러가** 잡아줌 |

### 겪은 버그와 배운 것
| 겪은 일 | 배운 것 |
|---|---|
| `case SlimeState::Chase:`로 상태를 바꾸려 함 | **case는 입구, return은 출구** |
| 이동하던 슬라임이 아래 case로 흘러내려 공격만 함 | case 이름표는 멈추는 곳이 아님 (fallthrough) |
| `break` 뒤에 return이 없어서 거리 6에서 갑자기 이동 | 돌려줄 값이 없으면 **아무 값이나 나온다**. 경고 0개 습관 |
| `return SlimeState::Idle`로 이동이 멈춤 (출력엔 안 보임) | **테스트가 확인하지 않는 경우**에 버그가 숨는다. `return s;` |
| `toString`에서 `return 0;` | `std::string`에 0을 넣으면 크래시 위험. 약속한 타입으로 돌려준다 |
| 고쳤는데 결과가 그대로 | 저장해야 컴파일러가 본다 |

### 테스트 결과 (경고 0개)
```
정지에서 시작  {10, 6, 5, 7, 8, 9, 4} → 정지 정지 적대적 적대적 적대적 이동 적대적
이동에서 시작  {10, 9, 5, 8, 9}       → 이동 이동 적대적 적대적 이동
```
두 번째 테스트에는 경계값 8을 직접 추가했다.
